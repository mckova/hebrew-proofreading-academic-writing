# כתיבה אקדמית בעברית תקנית — סקיל

סקיל אחד לכתיבה, לעריכה ולהגהה של טקסטים אקדמיים בעברית, בכל תחום דעת,
ובתוכו מנוע הגהה מקומי לפי כללי **האקדמיה ללשון העברית**.

**הכול רץ מקומית.** אין מפתחות API, אין שירות בתשלום ואין שליחת הטקסט שלך
לשירות חיצוני בזמן ההגהה. המנוע הוא כללים ומורפולוגיה, ולכן אותו טקסט מחזיר
תמיד את אותם ממצאים, וכל ממצא ניתן לאימות מול מקורו.

---

## התקנה

אין בנייה ואין `npm install`. מעתיקים את התיקייה אל תיקיית הסקילים:

```bash
git clone https://github.com/mckova/hebrew-academic-writing.git ~/.claude/skills/hebrew-academic-writing
```

ב-Windows (PowerShell):

```powershell
git clone https://github.com/mckova/hebrew-academic-writing.git "$env:USERPROFILE\.claude\skills\hebrew-academic-writing"
```

לפרויקט אחד בלבד, במקום לכל המשתמש: `<הפרויקט>/.claude/skills/hebrew-academic-writing`.

### מה נדרש

| | בשביל מה | בלעדיו |
|---|---|---|
| **Node 18+** | מנוע ההגהה (`engine/`) | אין הגהה אוטומטית; הידע והכללים שבסקיל עובדים |
| **Python 3** | `scripts/heb_api.py` — ניבים, החלטות האקדמיה, ניקוד, פסוקים | אין בדיקת ניבים ואין שליפת מקורות |

## מה יש בפנים

```
SKILL.md              ההוראות עצמן: סדר העבודה, כללי הברזל, טבלת הכלים
references/           13 קובצי ידע: סגנון, מבנה, טיעון, מילות קישור, פיסוק,
                      מבנה המשפט, ניבים, לשון תקנית, הפניות, ניקוד, מקרא
scripts/heb_api.py    שירותים חינמיים: ניבים, החלטות האקדמיה, ניקוד, פסוקים
engine/               מנוע ההגהה: 85 כללים, מורפולוגיה, לקסיקונים
```

### הידע

רישום לשוני ומבנה טיעון, מילות קישור על פני עשרים קטגוריות, פיסוק, מבנה
המשפט והסמיכות, ניבים ומטבעות לשון, לשון תקנית, שיטות הפניה וביבליוגרפיה,
ניקוד — ופרק נפרד לכתיבה במדעי היהדות ובחקר המקרא.

### המנוע

```bash
cd ~/.claude/skills/hebrew-academic-writing
node engine/dist/cli.js --register academic --file עבודה.txt
```

```
בכדי לבדוק את התכנית , כתבתי שלוש מסמכים בשנת תשפה. היות ואין לי נסיון.
    ↓
כדי לבדוק את התוכנית, כתבתי שלושה מסמכים בשנת תשפ״ה. היות שאין לי ניסיון.
```

| מה נבדק | דוגמאות |
|---|---|
| שגיאות נפוצות | בכדי, היות ו-, בגלל ש-, למרות ש-, במידה ו- |
| כתיב מלא | תכנית ← תוכנית, נסיון ← ניסיון, בטחון ← ביטחון |
| תחביר | התאם מין ומספר, יידוע בסמיכות, ״את״, שלילה, מילות היחס של הפועל |
| פיסוק וטיפוגרפיה | פסיק, גרש וגרשיים, מקף עברי, מירכאות, רווחים, אותיות סופיות |
| מספרים ותאריכים | שם המספר לפי מין שם העצם, שנים עבריות |
| מרשם וסגנון | אורך משפט, חזרות, שרשראות ״של״, קלישאות, מקצב |

ועוד: נטיית פועל בשבעת הבניינים, ניתוח צורה (שורש, בניין, גזרה, זמן, גוף),
סיווג שווא נע ונח, ניקוד אותיות השימוש, ומילות קישור לפי תפקיד.

**שלושה עקרונות שהמנוע בנוי עליהם**

1. **כל ממצא נושא מקור** — שם הכלל ומאיפה הוא בא: החלטת אקדמיה, מוסכמת
   עריכה או כלל בית. אפשר לחלוק על ממצא ולבדוק את מקורו.
2. **עדיף לפספס מאשר להתריע לשווא** — מילים שהכתיב ה״חסר״ שלהן הוא מילה
   תקנית אחרת (עֶשֶׂר, אֹרֶךְ, רָחָב, יְסוֹד, יָבוֹא) הוצאו מרשימת הכתיב המלא
   לגמרי. כלל שאין לו הכרעה ודאית מדווח כהצעה ואינו מתקן אוטומטית.
3. **ניקוד רק לפי בקשה** — ברירת המחדל היא כתיב מלא; `--nikud` מחזיר צורות
   מנוקדות, וגזרה שאין לה תבנית ייעודית מסומנת במקום להחזיר ניקוד שגוי בשקט.

התאם המין נשען על לקסיקון של מין שם העצם ולא על הסיומת בלבד: ״שלושה שולחנות״
ו״שלוש נשים״ נכונים ואינם מתוקנים, אף ששניהם נראים הפוכים מסיומתם.

## לקסיקונים אופציונליים

85 הכללים עובדים כמו שהם. מעליהם אפשר לבנות מקומית ארבעה לקסיקונים מורחבים
ישירות מן המקור:

```bash
cd engine
npm install
npm run harvest             # מאגר המונחים: ~2,000 זוגות כתיב חסר ← מלא
npm run harvest:decisions   # 400 החלטות רשמיות
npm run harvest:topics      # 224 עמודי נושא
npm run harvest:idioms      # 1,277 צורות ניב
npm run harvest:places      # 1,682 שמות יישובים — רשימת היתר
npm run harvest:syntax      # מדור ״תחביר וניסוח״
npm run enrich -- --file עבודה.txt   # לומד את אוצר המילים שבמסמך שלך
node dist/cli.js --lexicon           # מה נטען בפועל
```

הפלט נשמר ב-`engine/data/`, שאינו נכלל במאגר הזה.

**למה לא.** ל-`robots.txt` של אתר האקדמיה יש `Content-Signal: ai-train=no,
use=reference`, והמאגר נושא הודעת ״כל הזכויות שמורות״. לכן: שום דבר כאן אינו
מאמן מודל; נאספות עובדות מילוניות בלבד — צורות כתיב ומקבילות מונחים, לא
הגדרות ולא טקסטים; הבקשות נשלחות אחת-אחת בהשהיה ונשמרות במטמון; והפלט נשאר
מקומי. אין להפיץ את `engine/data/`.

## התאמה אישית

`profile.md` בתיקיית העבודה — שיטת ההפניות, הרישום המועדף, מין הכותב, הנחיות
העיצוב של המוסד ומונחון קבוע. הסקיל קורא אותו ומעדיף אותו על ברירות המחדל.

`hebrew-editor.config.json` בתיקיית העבודה — כיוונון המנוע: מרשם, כיבוי
כללים, אורך משפט מרבי, מונחון בית ורשימת מילים מותרות לשמות ולמונחי תחום.
תבנית: `engine/hebrew-editor.config.example.json`.
